# 図の記法

流れ・構成・階層・データの形・経緯・案の比較・位置づけ・数値の大小は、文章より図のほうが速く伝わる。図は言語名つきのコードブロックで書き、`ika export html` と `ika serve` が CSS だけで描く（Mermaid は使わない）。GitHub などではただのコードブロックとして読める。

- 1行が1要素。`#` で始まる行はコメント。区切りの `:` は全角の `：` でもよい
- 言語名のあとの文は図の説明になる（` ```seq 打刻の流れ `）
- 記法の誤りは `ika check` が行番号つきで指摘し、`ika export html` は書き出さずに止まる
- 自由に箱を置いて線を引く図（任意のグラフ）は描けない。構造や値で配置が決まる次の10種だけ
- `flow`・`tree` の箱の印は共通で、`*` 主役、`+` 成功・済み、`!` 問題。`名前 | 補足` で補足を添える。`matrix`・`bars` も `*` で主役を示す

| 言語名 | 図 | 書き方 |
|---|---|---|
| `seq` | シーケンス図 | `A -> B: 文`。`->` 呼び出し、`-->` 返り値（破線）、`=>` 強調。参加者は登場順に左から。`note A: 文` で注記 |
| `flow` | フロー・状態遷移 | 1行目に `a -> b -> ?判断`。判断のあとに字下げで `ラベル: c -> d` の枝。印は `?` 判断、`*` 主役、`+` 成功、`!` 問題。`名前 \| 補足`。戻り（差し戻し・やり直し）は鎖の最後に `^戻り先の名前`（「↩ 名前」の箱になる。線は引かない）。合流は描かない |
| `layers` | 層の構成図 | `名前 \| 補足 {new}: 札, 札`。上の段が下の段を使う。`{new}` 藍、`{keep}` 苔 |
| `er` | ER 図 | `表示名 英名` の下に字下げで `*主キー: 型`・`属性: 型`。関係は `A 1 -- 0..* B: 関係名`。線は隣り合う箱だけ（ほかは図の下に文字で出る） |
| `class` | クラス図（継承の木） | `子 : 親 <<abstract>>` の下に字下げで属性・操作、`--` で区画を分ける。関連は描かない |
| `timeline` | 年表 | `2026-10-23: 文`（`YYYY-MM-DD` か `YYYY-MM` だけ）。`? 未定: 文` は未定の項目 |
| `tree` | 木（階層） | 1行1節。上の行より深く字下げした行がその子。根は複数でもよい。サイトマップ・集約・ディレクトリ・目標の分解に |
| `matrix` | 2×2 | `x: 低い側 -> 高い側`・`y: 低い側 -> 高い側` と、象限 `右上`・`左上`・`右下`・`左下`。`右上 \| 象限の名前: 項目, *主役の項目`。象限の中の位置は決めない（書いた順） |
| `bars` | 数値の棒 | `名前: 値 \| 補足`。値は数＋単位（`7,788円`・`1.5万円`・`30%`）で、単位は全行でそろえる。長さは最大値に対する比。負の値は描けない。増え続ける観測は `ika data` に置き、言えることを書くときに使う |
| `compare` | 案の比較 | `名前 \| 説明` の下に字下げで `+ 長所`・`- 短所`・`= 結論`。採用した案だけ先頭に `*`（未決定なら付けない） |

```flow 申請の流れ
下書き -> 申請 -> ?承認する？
  はい: +承認済み

```

x: 数字で競う -> 体験で選ぶ
y: その場かぎり -> 積み上がる
右上 | 狙う場所: *自社
左上: 競合A, 競合B
```

スタート: 7,788円
*ビジネス: 26,136円 | 売れ筋
```
